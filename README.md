# n8n Workflow Automation Engine

Automated LinkedIn Content Curation, Ghostwriting, and Repurposing Engine powered by n8n, Google Gemini AI, and Apify.

## System Features
- **Apify LinkedIn Scraper Integration**: Scrapes posts from target profiles.
- **AI Content Classifier**: Filters relevant business & technology posts using Gemini AI.
- **AI Content Ghostwriter**: Rewrites content while maintaining original facts, hashtags, and attributions.
- **Google Sheets Curation**: Automatically catalogs and tracks processed posts.
- **n8n Automation Pipeline**: Local n8n workflow management.

## Quick Start
Double-click `n8n Server` on your Desktop or run:
```cmd
start-n8n.bat
```
Then navigate to `http://localhost:5678`.
